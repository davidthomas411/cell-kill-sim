  2. On cup_depth_over_radius (d / a), dasatinib lowered the donor median in only 1 / 3 paired donors (hd10: 0.500 -> 0.400; whereas hd2: 0.303 -> 0.383 and hd5: 0.316 -> 0.345; donor-stratified one-sided $p_{\text{lower}} = 0.749$).

  6. Test 7B — Within-donor Cox model (UNVERIFIED, restatement of Step 5b on same data):
