## Question

Can we build per-visit and per-chamber target death labels across all 502 chambers (`10,510` chamber-visits) from the deposited 2D 405-nm SYTOX projections (`*_MIPxy_405.tif`, `*_MIPxz_405.tif`) and 3D segmentation masks (`*_predictions.h5`), restricted to the target instance contacted by the tracked T cell and free of stage-edge imaging artefacts?

** Verification Notice: All Step 4 v2 death labels reported in this entry are UNVERIFIED and blocked at Gate `G2`.**

## Observations

1. **MIP projection verification**: On all 20 local 3D raw volumes, `MIPxy_405 == raw[0].max(axis=0).T` and `MIPxz_405 == raw[0].max(axis=1).T` match with `0 ADU` difference.
2. **Contacted-target filtering (`commit b055e23`, UNVERIFIED)**: Restricting the 2D target projections `b_xy`, `b_xz` from all raw target voxels `(pred == 2) | (pred == 4)` (v1) to the 3D segmented target instance contacted by Track 1 (`instance_seg_matlab_xyz`, `trace_num == 1`) removes bystander-only death calls.
3. **`MIP_ROI_0` late 405-nm saturation band (`commit b055e23`)**: In all `13 / 13` experiments, `MIP_ROI_0` at `visit >= 19` (`39 / 39` visits) has a left-edge vertical saturation band (`14,505–25,317 ADU`). Excluding visits with `median(mip_xy[:, 0]) > 404.0` and `mip_xy.max() > 5000` removes `9 / 13` artifact-only false-positive chamber deaths.
4. **Unverified condition kill rates (`trace_num == 1`, Any-Visit rule)**: Untreated high-killing `87 / 167` (`52.1%`, paper `Figure 5g`: `96 / 167 = 57.5%`), untreated low-killing `39 / 160` (`24.4%` full, `34 / 160 = 21.2%` in 200 min; paper: `44 / 163 = 27.0%`), dasatinib `8 / 89` (`9.0%` full, `6 / 89 = 6.7%` in 200 min; paper: `4 / 89 = 4.5%`).
5. **Defects found in subsequent visual review (`review-2026-10-28`)**:
   - Gallery panels (`death_surviving_19`, `death_surviving_24`, `death_killed_07`) drew raw `(pred == 2) | (pred == 4)` outlines rather than the contacted target instance, disagreeing with the v2 table labels.
   - `death_dasatinib_30` v5 reports `27 px` overlap while the dye speck sits outside the target contour in both views.
   - Dye-positive neighbours can overlap the target in 2D projection (`death_surviving_17`, `death_killed_05`, `death_killed_09`).
   - Signal margin is narrow (`404.0 ADU` threshold vs `~400 ADU` background; `death_killed_01` at `404.3 ADU`).

## Decision

Result is **UNVERIFIED** (`status: unverified` in `lab/registry.csv`, Step 4 blocked at Gate `G2`). Do not treat `step4_death_labels_v2` as verified ground truth until the gallery/label discrepancy, `death_dasatinib_30` overlap check, neighbour-overlap filtering, and threshold sensitivity analysis pass Gate `G2`.
