# Lab Handbook (`lab/handbook/`)

Reference documentation for the Cell-Kill-Sim dataset and verification pipeline:

- `data.md` — description of every dataset layer, storage path, and stage-gate dependency.
- `definitions.md` — formal definitions of voxel pitch, axial Z-spacing and resolution caveats, contact patch and cup depth descriptors, and the target death rule.
- `known-issues.md` — catalogue of measurement, segmentation, death-label, and mechanical-model issues identified during visual review, each linked to its lab notebook entry.
- `open-questions.md` — technical questions for the Fei lab regarding deposition metadata, axial scaling, and segmentation edge cases.
